# Delacroix technical notes

## Source and deployment

The maintainable source is `sites/delacroix-archive/`. The uppercase
`DELACROIX-ARCHIVE/` directory is generated by the shared direct-static builder
and is the committed input copied into the GitHub Pages artifact.

```text
sites/delacroix-archive/ -> .site-build/delacroix-archive/
                          -> DELACROIX-ARCHIVE/
                          -> docs/DELACROIX-ARCHIVE/
```

Public path: `/My-Website/DELACROIX-ARCHIVE/`.

Run:

```bash
npm run build:delacroix
npm run validate:sites
npm run build:pages
npm run validate:pages
```

## Runtime

- `index.html` is the semantic shell.
- `app.js` owns hash routing, progressive rendering, dialogs, filters and local
  reading state.
- `data.js`, `featured-works.js` and `research-content.js` are the multilingual
  content and evidence records.
- `styles.css` owns the three-room palette and responsive system.
- All publication images are local under `assets/`; museum and catalogue links
  are reader-initiated external destinations.

The site stores language, selected periods, saved works and free-form work notes
in the current browser's `localStorage`. It has no analytics provider, account,
cookie or note-upload endpoint.

## Path rules

Site assets use `./` relative paths. The footer logo intentionally uses
`../THE-LIVING-ATLAS/tsrat-logo.png`, which resolves both in the Pages artifact
and immutable repository preview. Do not replace the existing GitHub Actions
Pages architecture or edit the uppercase mirror directly.
