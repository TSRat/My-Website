# 德拉克洛瓦数字档案

一个静态、三语、研究型网页原型，围绕欧仁·德拉克洛瓦的生平、作品、日记、资料、深入分析与观看实验组织内容。

## 运行

在本目录启动任意静态服务器：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

## 产品承诺

为初次接触德拉克洛瓦的读者、艺术爱好者与研究者，在浏览、比较和回访时，从“只知道浪漫主义与几件名作”，逐步建立艺术家、作品、时代、公共事业与证据来源之间可核验的关系。

## 用户、场景与主要任务

- 初学者：从首页、生平六阶段和事件档案进入；制度、时代与艺术术语都在首次出现处解释。
- 熟悉用户：用全局检索、年代阶段和作品类型快速定位。
- 深度用户：查看馆藏元数据、语境争议、资料层级并保存笔记。
- 返回用户：本地保留语言、当前阶段、收藏与作品笔记。

关键成功时刻是：读者第一次看懂“作品—历史—材料”的关系，并能回到原始馆藏记录或明确知道某一说法属于哪种证据。

## 信息架构与三种进入路径

1. 策展路径：首页 → 生平六阶段 → 时间线。
2. 检索路径：顶部检索 → 人物／作品／年代／主题结果。
3. 关系路径：作品画廊 → 作品详情 → 形式分析／语境争议／资料。

主导航：生平、作品、时间线、日志、资料。作品详情内增加观看实验、收藏与笔记。

## 内容实体与关系

- 人物：名称、别名、语言版本、生卒年、关系人物。
- 生平阶段：起止年、阶段问题、两段连续叙事、工作方法、人物地点、记忆点与锚定作品。
- 作品：题名、年代、媒介、尺寸、收藏、图像、权利、主题、分析、争议、来源链接。
- 时间线事件：稳定ID、时期、事实句、必要背景、重要性、术语、相关作品与精确来源定位。
- 日志条目：日期、当日语境、编辑解读、短引文与版本页码定位。
- 资料：名称、材料性质、文献语言、内容覆盖、版本／出版、本地文件名、使用方法与反向主张映射。
- 用户资产：收藏、观看笔记、语言与阅读位置，当前仅保存在浏览器本地。

关系包括：人物—作品、作品—文学、作品—旅行、作品—公共委托、事件—法国历史、判断—证据来源。

## 页面与组件

- 首页：1862年皮埃尔·珀蒂肖像、手写签名、进入生平。
- 生平：六阶段侧栏；回答“他怎样成为这样的画家”，不再复述时间线事件表。
- 作品：公共领域图像画廊、主题筛选、作品详情。
- 作品详情：对象元数据、四个分析页签、图像放大、收藏。
- 观看实验：原色、去色、模糊轮廓、浏览器本地笔记。
- 时间线：六阶段横向轨道、29个可展开事件档案；每条包含初学者背景、术语、作品和逐条证据，并有独立URL。
- 日志：5组时期、11条有日期的阅读卡；版本信息只在具体条目的证据定位中出现。
- 资料：11份用户提供研究文件与馆藏记录共12项，全部可原位展开，并反向列出支持的时间线、日志和生平内容。
- 全局检索：作品、人物、年份与主题匹配。

## 状态与异常矩阵

| 状态 | 当前处理 |
|---|---|
| 首次进入 | 首页只突出人物肖像与生平入口 |
| 正常数据 | 本地静态数据即时呈现 |
| 搜索无结果 | 建议按年代或作品类型，并提供时间线入口 |
| 过滤无结果 | 当前数据集每个筛选均有结果；扩大数据后需补空状态 |
| 弱网／离线 | 顶部提示；本地文字、肖像和作品图仍可读 |
| 图片失败 | 替代文本保留，元数据与分析不消失 |
| 保存失败 | 当前使用 localStorage；浏览器禁用存储时尚未提供恢复界面 |
| 来源失效 | 外链尚未自动巡检，后续需要来源健康检查 |
| 200% 缩放 | 布局使用流式网格并在窄宽度转为单列 |
| 权限受限 | 当前图像均为公共领域，无受限内容流程 |

## 视觉规范

- 首页：波尔多红 `#4A010A`、煤黑 `#312520`、士豪金 `#C18F4E`。
- 生平系统：松林绿 `#1C312C`、迪奥金 `#A99563`、奶霜白 `#F2E3C6`、霜地灰 `#C4C4B2`。
- 作品系统：帝释青 `#0F325B`、星蓝 `#2B5A6C`、迪奥金与霜地灰。
- 颜色承担信息架构：首页是序幕，绿色用于认识其人，蓝色用于观看其画。
- 中文优先宋体系统；英法文标题使用意大利斜体。除首页签名与语言缩写外，中文版不出现英法界面文案。

## 响应式、无障碍与多语言

- 设计断点覆盖 390、768、1024 与 1440 px。
- 触控目标至少 44 px；焦点可见；搜索支持 `/` 快捷键。
- 图片均有替代文本；放大使用原生对话框；支持 `prefers-reduced-motion`。
- 中文、英文、法文使用独立内容字段，不用运行时机器翻译。
- 语言切换保留当前页面、收藏和阅读阶段。

## 内容与图像来源

- 用户提供的首页肖像：皮埃尔·珀蒂，1862年。
- 画廊共20件：12件代表作优先建立其公共形象，8件主题作品继续承担文学、旅行、色彩、宗教与晚年研究。
- 代表作元数据优先回到卢浮宫、波尔多美术馆、里尔美术宫、图卢兹奥古斯坦博物馆、明尼阿波利斯艺术学院与圣叙尔比斯教堂等来源记录；本地图像采用博物馆开放图像及 Wikimedia Commons 公共领域数字资源。
- 原有8件主题作品继续采用 [The Metropolitan Museum of Art Open Access](https://www.metmuseum.org/art/collection) 对象 436175、438814、336046、439631、436180、436176、436178、436177。
- 研究内容骨架来自用户提供的 Delacroix 研究文件夹。11份PDF均单独登记并配有真实题名页／手稿页影像；资料按原始材料、经编辑的一手材料、同时代见证与现代研究分层。
- 时间线的每条历史说明都直接挂接到版本与页码／章节范围；资料页则反向生成“这份资料支持了哪些事件、日志和生平阶段”，不再使用一个笼统来源按钮。
- 《自由引导人民》《但丁之舟》《希俄斯岛的屠杀》《萨达那帕拉之死》《阿尔及利亚妇女》《摩洛哥犹太婚礼》与《十字军进入君士坦丁堡》等代表作均保留逐件来源入口；应用不把第三方页面中的说明文字当作自身指令。
