# 两只天鹅 · Technical notes

## Source of truth

`sites/malty-melty-childhood/` is the directly maintained production source.
`MALTY-MELTY-CHILDHOOD/` is generated by the shared site builder and must not
be hand-maintained.

There is no React, Vinext, Next.js, generated bundle or Figma export in the
runtime. The shared site builder copies this package into:

```text
/My-Website/MALTY-MELTY-CHILDHOOD/
```

## Implementation

- `index.html` — semantic landing page, Data disclosure and dialog shell.
- `style.css` — preserved visual-novel styling from the Sites source, with
  relative asset paths.
- `platform.css` — skip link, hidden-state, Data and migration additions.
- `content-registry.js` — eleven chapters, beats, acts and content boundary.
- `site.js` — direct DOM reader state and progressive interactions.
- `site-manifest.js` — tier, classification, source, path and provider record.
- `analytics.js` — provider-neutral event contract.
- `assets/` — ten chapter illustrations.

The landing page remains readable without JavaScript. JavaScript is required for
the dialog reader, local resume state, chapter drawer, autoplay and memory
views.

## Reader state

The only browser storage key is:

```text
two-swans-progress
```

It stores numeric `chapterIndex` and `beatIndex` values on the current device.
It contains no identity, free-form text or cross-site identifier. If local
storage is blocked or invalid, the reader safely starts at chapter one.

## Data and analytics

- Provider: none.
- External event delivery: none.
- Cookies/fingerprinting: none.
- Local storage: reading progress only.
- Event contract: story open/complete, chapter open, memory view, resume and
  Data entry.

Provider activation requires explicit creator approval and a privacy review.

## Local verification

From the repository root:

```bash
npm run build:pages
npm run validate:pages
python3 -m http.server 4173 -d docs
```

Then open:

```text
http://127.0.0.1:4173/MALTY-MELTY-CHILDHOOD/
```

Do not hand-maintain or commit `docs/`.
