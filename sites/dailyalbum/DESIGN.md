# DailyAlbum design preservation

Preserve the existing record motif, charcoal/ivory surfaces, coral emphasis, blue slice, and thin gold line. Native system fonts; no web-font requests. The original HTML/CSS is the design baseline, not a Figma file. No Figma approval is claimed.

The responsive site has a two-column introduction and three explanatory feature cards on wide screens; below 760px, those become a single reading column. The eight pages share navigation, language switching and compact footer. Text-only inner pages use an 800px reading column. Keep automatic light/dark appearance and keyboard focus.

The only migration addition is the existing portfolio's linked creator logo in the footer. See `design/implementation-map.md` for the implementation contract and six-stage coverage.
