# DailyAlbum technical handoff

- Source: `sites/dailyalbum/`.
- Build: `npm run build:dailyalbum` using the existing direct-static builder.
- Generated mirror: `DAILYALBUM/`; do not edit it directly.
- Production route after merge/deployment: `https://tsrat.github.io/My-Website/DAILYALBUM/`.
- Preview: exact-commit static mirror; no production merge required.
- No JavaScript runtime, dependencies, backend, cookies, forms, analytics, or persistent site storage.
- Contacts use `mailto:`. Site traffic is served by GitHub Pages; emailed support requests use the owner's email provider.
- Relative links preserve the repository prefix, inner-page direct entry and bilingual routes.

The app repository retains a release snapshot of the eight website pages. When site support/privacy content changes, synchronize that snapshot before the next app release. Only approved public pages are copied into this repository.
