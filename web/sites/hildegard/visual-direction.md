# Hildegard 视觉方向

Status: creator approved · 2026-07-28

## 方向名称

**Viriditas Codex II — Illuminated Leaves**

它不是“中世纪主题皮肤”，而是把手抄本与宗教艺术的构图方法转译为现代阅读界面。

## 视觉语法

- **羊皮纸页**：温暖但接近纯色的底，不使用影响对比度的仿旧噪点。
- **金叶**：只用于页框、分隔线、初始字与关键坐标；面积保持克制。
- **朱红题注**：页码、章号、证据类别和编辑提示。
- **深蓝异象场**：只用于异象、音乐和未知语言的视觉页，不泛化为全站背景。
- **Viriditas 绿色**：主导航、生命力、知识与植物学线索。
- **宗教艺术对称**：首屏与关键过场使用轴线、圆轮、祭坛式上下关系，但正文保持非对称编辑网格。
- **手抄本边注**：注释成为真正的信息层，不是装饰卡片。
- **装饰首字母**：每章第一页使用一个大号朱红 / 金色首字母，兼具定位与节奏。

## 页面家族

1. **Series Portal**：纪念性人物图像 + 手抄本圆轮 + 系列坐标。
2. **Primer Leaf**：六个短事实排成抄本索引，不做通用圆角卡片。
3. **Epistolary Leaf**：以书信、封印和边注构成叙事引子。
4. **Manuscript Leaf**：羊皮纸、窄正文、边注与史料图片。
5. **Vision Leaf**：深蓝场、金色同心结构与冷色图像。
6. **Botanical Leaf**：Viriditas 绿色、根系 / 枝条结构与自然知识。
7. **Archive Leaf**：索引编号、时间轴、证据表与文件式分隔。

## 图片策略

- 优先使用当前仓库中已经记录来源与许可的 5 张历史 / 纪念图像。
- 第 02、05 章继续使用创作者提供的《Vision》剧照，并始终标注“现代视觉再现”。
- 第 06 章继续使用创作者提供的现代未知之语转录，并始终标注“现代转录示意”。
- `Women Story/Hildegard/photo 23.03.17` 中的手抄本、圣像、乐谱可作为构图参考；在来源和许可未核实前，不复制进公开仓库。
- SVG 只承担圆轮、藤蔓、根系与星点等结构装饰，不冒充历史配图。

## 禁止项

- 哥特式尖拱模板、塔罗牌、星座 / 水晶、新时代紫色。
- 仿皮封面、烧焦纸边、重噪点、假蜡封和主题乐园式复古。
- 玻璃拟态、漂浮圆角卡片、无意义渐变。
- 把后世或现代图像写成希尔德加德的历史肖像。
- 用装饰牺牲中文正文对比度、字号或行长。

## 色彩配额

- 羊皮纸 / 浅色面 ≥ 40%
- Viriditas 绿色 ≥ 30%
- 深蓝异象场 ≤ 20%
- 金叶 ≤ 8%
- 朱红仅作索引与警示，不成为大面积背景
