# Hildegard 产品规格

Status: creator approved · 2026-07-28

## 产品目标

把现有长篇人物站改造成一本可以逐页阅读的数字手抄本。读者既能在 30 秒内认识希尔德加德，也能继续进入八章完整论证、史料分层与视频。

## 核心读者任务

1. 快速知道她是谁、何时何地生活、为何值得认识。
2. 理解她的权威不是单一“女性反抗”故事，而是神启、学识、修道院制度与阶级位置共同形成。
3. 分清历史事实、学术解释、叙事框架和现代视觉再现。
4. 在长文中知道自己读到哪里，并能稳定分享具体页。
5. 需要时进入视频、来源和数据说明，而不被嵌入媒体打断。

## 功能要求

- 20 个叙事页、3 个附录、稳定深链锚点。
- 00–08 章级导航，20 页阅读进度，章内页码。
- 前后页控制与“返回本章起点”能力。
- 可关闭的移动导航；键盘可操作；可见焦点状态。
- 图片标题明确区分历史图像、后世纪念图像、现代剧照与现代转录。
- 视频点击后才载入 iframe，未载入时提供外链。
- 无 JavaScript 时正文、导航、图片与来源仍可读。
- `prefers-reduced-motion` 下禁用非必要过渡。

## 内容保护

- 保留现有 00–08 顺序、核心段落、引文、年代和限定语。
- 保留“性别上的越界与阶级上的保守并存”。
- 不把《Vision》剧照称为历史现场。
- 不把后世雕像或纪念图像称为肖像。
- 不将学术解释写成确定事实。
- 不使用来源和授权未核实的本地 Photo 文件作为公开站点素材。

## 成功标准

- 首屏 10 秒内说明系列、人物、年代、地域、身份与核心矛盾。
- 第 01 页在一个移动屏幕内可扫描主要坐标。
- 正文基础字号不低于 18px；关键元数据不低于 14px。
- 320px 宽无横向滚动；图片、表格与时间线不溢出。
- 任意 `#screen-xx` 深链落地后，无需等待动效即可读到该页标题和摘要。
- 所有现有章节与附录内容仍可访问。

## 非目标

- 不增加账户、评论、搜索或后台。
- 不新增未经创作者批准的英文路由。
- 不改变 GitHub Pages 路径、构建体系或分析供应商。
- 不把单页改成 20 个独立 HTML 路由。
