# Typography and layout

- Body：Noto Serif SC 18 / 36。
- Meta / Glossary：Noto Sans SC 15 / 24。
- Arabic：Amiri + `dir=rtl lang=ar`。
- Desktop：70/30；Tablet：60/40；Mobile：100% + 50svh Bottom Sheet。
- 标题 balance，正文 pretty，保持中文逻辑断点和 orphan/widow 控制。
- 六篇笔记目录：桌面说明/索引双栏，标题使用正文衬线层级，卷册元数据使用 Sans 12px；移动端改为单栏，每篇笔记保持独立可点击行且不截断标题。
