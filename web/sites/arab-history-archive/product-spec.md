# Product / UX specification

- Primary job：连续阅读六册阿拉伯通史笔记，并在不离开阅读位置时查术语。
- Audience：创作者本人及个人知识库读者。
- Main action：从六篇笔记目录进入对应卷册或向下连续阅读；辅助 action：打开注疏。
- Failure gate：出现笔记来源之外的历史评价、未来卷册被虚构命名、No-JS 正文缺失、移动注疏遮住全局导航。
- Route：`/My-Website/ARAB-HISTORY-ARCHIVE/`。
- Future growth：卷册数量由 registry 决定，不在 UI/代码中写死。
