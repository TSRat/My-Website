# Six-stage handoff

1. Product / UX：批准的单路由长卷、注疏任务、失败门槛与未来卷册模型。
2. Visual exploration：采用用户 Handoff Packet 的渐进色、典籍排版与克制的抽象纹理；未启用来源不明图片。
3. Figma design system：完整 Foundations、Components、Key Screens、Interaction 和 Handoff。
4. Interactive prototype + design QA：桌面/移动状态在 Figma；生产原型实现 Era Observer、注疏与 Bottom Sheet；Antigravity 扩展 QA pending。
5. Production engineering：仓库内 Markdown → static HTML 生成链、source/mirror、Pages、Preview、PR。
6. Data / analytics：provider-neutral 本地事件契约，无第三方追踪、Cookie 或持久化。

Capability usage：Product Design plugin 未另开方向探索，因为用户已经批准完整产品/体验契约；Creative Production 未生成历史图像，因为资产 provenance 未确认；Data Analytics 未接 provider，因为当前明确要求隐私优先的空状态。
