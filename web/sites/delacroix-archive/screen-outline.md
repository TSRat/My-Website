# Delacroix Archive screen outline

| Screen / route | Beginner question | Primary evidence or action |
| --- | --- | --- |
| `#/home` | Who is this person? | 1862 Pierre Petit portrait, signature, biography entry |
| `#/life` | How did he become this painter? | Six developmental chapters, methods, people, anchor works |
| `#/works` | Which works define and complicate his reputation? | 20-work filtered gallery |
| `#/work/<id>` | What am I looking at, and why does it matter? | Metadata, form, context, guided four-step viewing experiment, source record |
| `#/timeline` | What happened, when, and what must I know first? | Six periods and 29 expandable dossiers |
| `#/timeline/<id>` | Can I cite and revisit one event directly? | Background, meaning, terms, works, exact evidence |
| `#/journal` | What did work and life look like on a dated day? | Five periods and 11 exact-date readings with French excerpts, translations and page locators |
| `#/sources` | Which material supports which claim? | 13 in-place source records and reverse mappings |
| `#/sources/<id>` | What exactly is this source used for? | Full citation, identifiers, access status, image and supported records |

Global states: language, search dialog, mobile navigation, image dialog,
offline notice, saved work and local note.

On a route change the visible page heading receives focus without causing a
second scroll jump. In-page period, filter and expansion changes preserve the
reader’s current scroll position. Mobile menu labels switch between open and
close, and opening the menu focuses its first destination.
