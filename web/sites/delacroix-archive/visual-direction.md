# Delacroix Archive visual direction

The site borrows from nineteenth-century salon catalogues, dark museum rooms,
gold rules, photographic mounts and the painter's own preference for charged
colour. It does not imitate a leather book or add ornamental historicism.

- **Prologue:** Bordeaux `#4A010A`, coal `#312520`, gold `#C18F4E`.
- **Life / evidence:** pine `#1C312C`, gold `#A99563`, cream `#F2E3C6`.
- **Works / looking:** imperial blue `#0F325B`, star blue `#2B5A6C`.
- **Shape:** square edges, hairlines and large editorial fields.
- **Imagery:** real artwork and source-page images carry evidence; decorative
  substitutions must not be presented as historical records.

The palette changes when the reader changes activity, so colour is part of the
information architecture rather than a set of interchangeable themes.
